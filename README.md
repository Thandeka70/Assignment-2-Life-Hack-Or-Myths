# Assignment-2-Life-Hack-Or-Myths
This is my Life Hack Or Myth application app.
This app is a quiz app that quizzes users about life hacks
in this application is used arrays to store my quiz questions, answers and explaintions
the data type used the for the questions and answers is the string data type
i used multiple TextViews and Buttons so that my app can have multiple feature
i created 3 interfaces in this application so that the user can have 3 different screens of the app 
where they can see the welcome screen , the quiz screen and the score screen
i did my app testing by creating a workflows file
